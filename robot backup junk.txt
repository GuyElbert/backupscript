Set up ssh keys

1. Set up passwordless SSH authentication
Generate an SSH key pair if you don't have one, using $ ssh-keygen on your local machine.
Copy the public key to the remote server.
Use the ssh-copy-id command, replacing user and remote_host with your remote username and IP address or hostname:
$ ssh-copy-id user@remote_host.
You will be prompted for the remote user's password one last time.
Test the connection by logging in to the remote server.
You should not be asked for a password: $ ssh user@remote_host.

Automatic tarball script

#!/bin/bash

# Define variables
SOURCE_DIR="/path/to/your/source_directory"  # Directory to archive
BACKUP_DIR="/path/to/your/backup_location"  # Where to store the tarball
TIMESTAMP=$(date +%Y-%m-%d_%H-%M-%S) # Add a timestamp to the filename
TARBALL_NAME="backup_$TIMESTAMP.tar.gz" # Name of the tarball

# Create the tarball (c=create, z=gzip compress, v=verbose, f=file)
tar -czvf "$BACKUP_DIR/$TARBALL_NAME" "$SOURCE_DIR"

# Optional: Remove older backups (e.g., older than 7 days)
find "$BACKUP_DIR" -mtime +7 -name "*.tar.gz" -delete


Script for automatic backup using cron

1. Create the Backup Script
Create a bash script (e.g., check_and_backup.sh) that checks the directory size and initiates the backup if the size limit is reached.
bash
#!/bin/bash

# Directory to monitor
SOURCE_DIR="/path/to/your/directory"

# Backup destination directory
DEST_DIR="/path/to/your/backup/location"

# Size threshold in megabytes (e.g., 500 MB)
SIZE_THRESHOLD_MB=500

# Get the directory size in megabytes using 'du -sm'
# The 'du -sm' command outputs size in MiB followed by the directory name.
# 'awk' is used to extract just the size value.
CURRENT_SIZE_MB=$(du -sm "$SOURCE_DIR" | awk '{print $1}')

# Check if the current size exceeds the threshold
if [ "$CURRENT_SIZE_MB" -ge "$SIZE_THRESHOLD_MB" ]; then
    echo "Directory size ($CURRENT_SIZE_MB MB) exceeds threshold ($SIZE_THRESHOLD_MB MB). Starting backup..."

    # Create a timestamped archive file name
    BACKUP_FILE="backup-$(date +%Y%m%d%H%M%S).tar.gz"

    # Create a compressed archive of the directory using tar
    # -c: create, -z: gzip compression, -f: specify file name
    tar -czf "$DEST_DIR/$BACKUP_FILE" "$SOURCE_DIR"
 
    echo "Backup completed: $DEST_DIR/$BACKUP_FILE"
else
    echo "Directory size ($CURRENT_SIZE_MB MB) is within the limit ($SIZE_THRESHOLD_MB MB). No backup needed."
fi


Open the crontab editor by running:
bash
crontab -e
Add a line to run your script at the desired frequency. For every 30 minutes, you would add:
bash
*/30 * * * * /path/to/your/script/check_and_backup.sh >> /var/log/backup_log.log 2>&1
This command will run the script every 30 minutes and redirect its output to a log file for monitoring.

For more immediate action, you can use the inotify-tools package to monitor the filesystem for changes in real-time and trigger the script. This method is more complex than cron but more responsive to size changes.
By combining the du command for size checking and tar for archiving within a shell script automated by cron, you can effectively manage directory backups based on a specific size threshold.

Python backup script

#!/usr/bin/env python3
import os
import subprocess
import sys
from pathlib import Path
from datetime import datetime

# --- Configuration ---
SOURCE_DIR = "/path/to/your/source/directory"
BACKUP_DIR = "/path/to/your/backup/destination"
SIZE_THRESHOLD_GB = 10  # Threshold in Gigabytes
# ---------------------

def get_dir_size(path):
    """Calculates the total size of a directory in bytes."""
    total_size = 0
    try:
        for entry in Path(path).rglob('*'):
            if entry.is_file():
                total_size += entry.stat().st_size
    except FileNotFoundError:
        print(f"Error: Source directory not found at {path}")
        sys.exit(1)
    except Exception as e:
        print(f"An error occurred while calculating directory size: {e}")
        sys.exit(1)
    return total_size

def run_backup(source, destination):
    """Executes the rsync command for backup."""
    # Create a timestamped directory for the current backup
    timestamp = datetime.now().strftime("%Y-%m-%d_%H-%M-%S")
    destination_path = Path(destination) / f"backup_{timestamp}"
    destination_path.mkdir(parents=True, exist_ok=True)

    print(f"Directory size exceeds threshold. Starting backup to {destination_path}...")
 
    # Use rsync for an efficient backup. Options include:
    # -a: archive mode (preserves permissions, timestamps, etc.)
    # -v: verbose
    # --delete: deletes files in the destination that are not in the source
    # Note: For Time Machine style incremental backups with hardlinking unchanged files,
    # you might need a more sophisticated script or dedicated tool like rsnapshot or rsync-time-machine.py.
    rsync_cmd = ["rsync", "-av", "--delete", str(source), str(destination_path)]
 
    try:
        subprocess.run(rsync_cmd, check=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
        print("Backup completed successfully.")
    except subprocess.CalledProcessError as e:
        print(f"Backup failed. Stderr: {e.stderr.decode()}")
 	print(f"Stdout: {e.stdout.decode()}")
        sys.exit(1)

def main():
    # Convert threshold to bytes
    threshold_bytes = SIZE_THRESHOLD_GB * 1024 * 1024 * 1024

    current_size = get_dir_size(SOURCE_DIR)
    print(f"Current directory size: {current_size / (1024*1024*1024):.2f} GB")

    if current_size >= threshold_bytes:
        run_backup(SOURCE_DIR, BACKUP_DIR)
    else:
        print("Directory size is within the limit. No backup needed at this time.")

if __name__ == "__main__":
    main()
